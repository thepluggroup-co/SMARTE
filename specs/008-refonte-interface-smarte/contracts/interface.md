# Contrat d’interface

| Interaction | Engagement observable |
| --- | --- |
| Changer d’espace ou de lieu | Afficher les sélecteurs distinctement. Mettre à jour thème, destinations et périmètre, avec repli vers un écran autorisé. |
| Naviguer par menu ou indicateur | Marquer la destination active. L’indicateur cliquable ouvre la liste avec le périmètre et les filtres annoncés. Sur mobile le menu se ferme et le focus rejoint le titre. |
| Ouvrir ou fermer une fiche courte | Sur ordinateur, ouvrir un panneau. Sur mobile, afficher une vue pleine largeur. Échap ou Retour ferme selon le contexte. Restaurer la liste, le défilement et le focus. |
| Rechercher | Limiter les résultats au périmètre autorisé de l’espace actif. Conserver la saisie et montrer les états de chargement, résultat vide ou erreur. |
| Enregistrer ou quitter | Signaler l’enregistrement, afficher l’erreur près du champ, conserver les valeurs saisies et traiter la sortie d’un formulaire modifié. |
| Réduire les animations | En mouvement réduit, supprimer les déplacements animés. Le focus et les messages restent disponibles. |
| Travailler hors ligne ou imprimer | Afficher l’état réseau et de synchronisation de la caisse. Utiliser les formats et mentions métier existants à l’impression. |

Les pages autonomes conservent leurs adresses et leurs paramètres de lien. Les permissions s’appliquent à la navigation et aux accès directs. Voir le [modèle d’état](../data-model.md) pour les règles de restauration.
